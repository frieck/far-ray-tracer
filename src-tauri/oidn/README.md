# Open Image Denoise

`tools/fetch_oidn.sh` fills this folder with Intel Open Image Denoise for this computer, or
for the platform it is given. The app bundle carries the folder, and the command line reads it
in a checkout. Without the libraries, the engine denoises with its own filter.

The libraries are not kept in git; their licenses (Apache 2.0) come with them, in `licenses`.
